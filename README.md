# CAPSTONE-CLIP

Python scripts exported from the original CAPSTONE-CLIP research notebooks and training code. All Python files contain zero comment tokens and no docstrings.

## Layout

- `capstone_clip.py`: latest single-file paired decontamination pipeline from 29 October.
- Other `.py` files: original experiment, postprocessing, audit and statistical workflows, including historical versions. These are independent workflows, not steps to execute sequentially.
- `conversion_manifest.json`: source-to-script mapping and SHA-256 checksums.
- `requirements.txt`: dependency names inferred from imports; versions were not locked by this export.

## Execution

Python 3.12 or newer is required for syntax used by historical scripts. Install dependencies with `python -m pip install -r requirements.txt` in a suitable GPU environment.

The original workflows target Google Colab and expect datasets, cached features and archived outputs under `/content/drive/MyDrive/CAPSTONE_CLIP_RemoteSensing`. Use a Colab environment or adapt these paths and the Drive mounting step for your machine. `google.colab` is supplied by Colab.

Run `python capstone_clip.py` in that configured environment. Its original default mode is `rerun`, which starts training. Review the `MODE` and path settings first. Other scripts retain their original settings and side effects.

Dataset imagery and feature caches are not included. Existing run artifacts are not regenerated by converting the source files. The overlap audit reports human review as incomplete.

## Validation

All 22 Python files were parsed and compiled without executing training. Comment-token checks passed. AST round-trip checks passed after removing standalone documentation strings; notebook future imports were moved to the beginning of the exported script where required. Scientific computations were not rerun.
